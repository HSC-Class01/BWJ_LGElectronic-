# 2010–2014 legacy data

OpenDART financial-statement APIs are documented as providing financial-year data from 2015 onward. Do not invent pre-2015 values. If 2010–2014 figures are verified from original LG Electronics DART filings, place them in `legacy_financials.csv` with columns such as:

`year,period,revenue,operating_income,pretax_income,net_income,assets,current_assets,cash,inventory,liabilities,current_liabilities,equity,controlling_equity`
