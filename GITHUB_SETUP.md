# GitHub setup

1. Add repository secret `DART_API_KEY` under Settings → Secrets and variables → Actions.
2. Settings → Pages → Deploy from a branch → main → /docs.
3. The dashboard URL is https://hsc-class01.github.io/BWJ_LGElectronic-/
4. Run Actions → Update LG Electronics DART data → Run workflow once for the first collection.
5. Monthly automation runs on the 1st at 00:00 UTC (09:00 KST).
